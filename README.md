# Parol6 rosHumble experimental code

Experimental ROS 2 Humble code for the PAROL6 robot arm. This is a work in
progress and a learning workspace. For now it only contains two minimal nodes
that log a message once per second, one in Python and one in C++.

| Package | Build type | Language | Executable |
|---|---|---|---|
| `test_node_python` | `ament_python` | Python | `test_node_python` |
| `test_node_cpp` | `ament_cmake` | C++ | `test_node_cpp` |

## Layout

```text
ros2_robot_ws/
├── src/                     # all source code
│   ├── test_node_python/
│   └── test_node_cpp/
├── .vscode/
│   └── c_cpp_properties.json   # C++ IntelliSense config for ROS 2 Humble
├── .gitignore
├── LICENSE
└── README.md
```

`build/`, `install/` and `log/` are generated by `colcon build` and are not
stored in git. You recreate them on every machine by building.

## Tested environment

| Component | Version |
|---|---|
| OS | Ubuntu 22.04 LTS |
| ROS 2 | Humble (`ros-humble-desktop`) |
| Python | 3.10 |
| C++ compiler | g++ 11.4, C++17 |
| CMake | 3.22 |
| Build tool | colcon (`python3-colcon-common-extensions`) |

ROS 2 Humble targets Ubuntu 22.04. Other Ubuntu versions are not supported by
this setup.

## Set up on a new machine (one time)

1. Install ROS 2 Humble following the official guide, using the
   `ros-humble-desktop` variant:
   <https://docs.ros.org/en/humble/Installation/Ubuntu-Install-Debs.html>

2. Install the build tools:

   ```bash
   sudo apt install build-essential cmake python3-colcon-common-extensions
   ```

3. Clone this repository into your home directory:

   ```bash
   git clone https://github.com/Luca40mx/Parol6-rosHumble-experimental-code.git ~/ros2_robot_ws
   ```

4. Build the workspace:

   ```bash
   cd ~/ros2_robot_ws
   source /opt/ros/humble/setup.bash
   colcon build
   ```

5. Optional: make new terminals source ROS and this workspace automatically by
   adding these lines to `~/.bashrc`:

   ```bash
   source /opt/ros/humble/setup.bash
   if [ -f ~/ros2_robot_ws/install/setup.bash ]; then
     source ~/ros2_robot_ws/install/setup.bash
   fi
   ```

## Daily use

```bash
cd ~/ros2_robot_ws
colcon build                      # only after changing code
source install/setup.bash         # only in terminals opened before the build

# Terminal 1
ros2 run test_node_python test_node_python
# Terminal 2
ros2 run test_node_cpp test_node_cpp
# Terminal 3
ros2 node list
ros2 node info /test_node_python
ros2 node info /test_node_cpp
```

Stop a node with `Ctrl+C`.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `Package '...' not found` | The workspace is not sourced: `source ~/ros2_robot_ws/install/setup.bash` |
| Code changes have no effect | Rebuild with `colcon build`, then source again |
| `ros2 node list` is empty | The nodes are not running, or `ROS_DOMAIN_ID` differs between terminals |
| Red squiggles on `#include "rclcpp/rclcpp.hpp"` in VS Code | Reload the window; make sure the C/C++ extension (`ms-vscode.cpptools`) is installed |
